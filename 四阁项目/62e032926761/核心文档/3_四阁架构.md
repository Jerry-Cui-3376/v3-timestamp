# 四阁架构

## 定义
知识阁 = 参考书（事实、数据、领域知识）
经验阁 = 笔记本（做过的事、踩过的坑）
记忆阁 = 名片（用户是谁、怎么沟通最高效）
技能阁 = 工具箱（可复用操作流程）

## 记忆阁分层

### 日常记忆
- session对话记录天然覆盖，不额外存储
- "今天聊了什么、让AI查了什么"

### 长期记忆
- 近期稳定但仍可能变化的信息（一个月以内）
- "最近在忙四阁项目、上周调了dispatcher"
- 超过一个月未更新 → 自动沉淀到深层潜意识

### 潜意识（浅层）
- session结束后接收沉淀物
- 临时存储 + 处理 + 分发 → 清空

### 潜意识（深层）
- 真正的永久存储，完整记录用户画像变化轨迹
- 每条带时间戳，只追加不删除
- 调用时只取每个维度最新值，历史不加载但可追溯
- 长期记忆超期未更新 → 自动沉入深层
- "我是软件公司老板"、"我妈是谁"、"我的电话号码"

### 维度机制
- 维度不预定义，自由增长
- 通过关键词重叠自动判断新旧：重叠高=同维度更新，重叠低=新维度
- 相当于一张动态Excel：时间戳纵向，维度横向，新维度自动加列

## 串联
经验阁是枢纽
  → 经验自带 Skill
  → 不确定时查知识阁补充
  → 记忆阁始终伴随（极简）
  → 都没找到 → 诚实说不确定 → 去查 → 存回来

## 原则
- 模型自带知识是底子，四阁补缺口
- 管线机械化：规则匹配，不让模型做判断
- 首次空白启动是正确的，后续启动带着积累
- "更懂你"不是学语气讨好，是时刻知道你是谁、你的变化、你的上下文
- 不确定就去查 = 刻进骨头里的铁律
- 存储膨胀但调用精简：存得下所有，喂给模型的只有当前需要的

## 使命
让所有人在轻量化环境里拥有能识别意图、精准执行的AI
